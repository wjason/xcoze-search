# 国内站内检索

**简体中文** | [English](china-site-search.en.md)

## 巨潮资讯公告

`cninfo` 使用巨潮网站公开的全文检索入口，返回公告标题、发布日期、证券代码、市场字段及 PDF 地址，不需要 Key。

```bash
python3 scripts/xcoze_search.py search '贵州茅台 2024 年度报告' --platform cninfo
python3 scripts/xcoze_search.py search '上市公司 年度报告' --platform cninfo
```

每次读取第一页，最多返回 10 条，不自动翻页。这里的“全文检索”指检索公告索引，输出不包含 PDF 全文。需要引用具体数据时，继续读取报告。发布日期与报告年度分别判断，例如 2024 年报可能在 2025 年发布。

查询明确要求“上市公司”时，使用网站公开的股票类别筛选，避免混入基金、债券报告；其他查询保持其原有范围。结果保留证券代码与市场，不把同一公司的 A 股、港股报告合并为一份，也不据此提供实时行情。不同格式的公告、复杂组合条件和全量下载不属于当前适配范围。

## 国家统计局站内搜索

`nbs-search` 使用统计局搜索页面选用的 `api.so-gov.cn` 后端，并固定统计局站点标识。查询会发送给该搜索服务，返回链接限制在 `stats.gov.cn`。它不是国家数据数据库的数值查询接口。

```bash
python3 scripts/xcoze_search.py search '2026年9月 居民消费价格' --platform nbs
python3 scripts/xcoze_search.py search '2026年10月 制造业 采购经理指数' --site stats.gov.cn
```

每次读取一页 10 条，按请求数量返回。明确的年月问题按标题中的统计期排除明显冲突，并优先排列标题与主题匹配的页面；不把摘要中的对比月份、网页发布日期当成所问统计期。发布日期保留搜索服务给出的精度，解释数值及统计口径仍需读取原文。

自动搜索 `--platform nbs` 或 `--site stats.gov.cn` 时优先使用站内检索。原来的近期栏目筛选仍可用 `--provider nbs` 显式调用。

## 范围与失败处理

这两条路径都不依赖 Exa、Parallel、宿主搜索或浏览器，也不增加 Python 运行依赖。接口来自公开网页所使用的入口，不代表服务商提供稳定的开发者 API 或可用性承诺。

日期范围、语言、正文返回等未适配参数会报错或使该入口退出自动候选，不静默丢弃用户条件。访问拒绝会暂停该入口，后续仅使用当前模式允许的来源；免费模式不会调用带用户 Key 的服务。空结果、访问失败和来源冷却分别报告。
