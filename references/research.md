# 调研搜索与证据

**简体中文** | [English](research.en.md)

`search` 用于定位资料；`research` 在同一任务预算内搜索、按需读取原文，并给出引用片段与证据缺口。最终结论仍由调用它的 Agent 核验，不另外调用模型服务。

```bash
python3 scripts/xcoze_search.py research 'asyncio TaskGroup' --platform python-docs --question '任务失败后其他任务会怎样？' --require-topic TaskGroup --require-topic ExceptionGroup
python3 scripts/xcoze_search.py research '储能' --platform government-procurement --region 广东 --notice-type tender --start-date 2026-10-22 --end-date 2026-11-22 --require-topic 储能 --require-topic 截止时间
```

## 工作方式

1. 保留原问题，按既有偏好和任务范围选择兼容来源。所有站点、日期、地区和公告阶段继续生效；不为获得结果丢弃筛选。
2. 搜索后按需读原文。已知官方站点优先原生读取；公告目录仅沿页面实际提供的链接进入正文，最多一层。
3. 检查原文中是否有关键主题、是否取得足够的不同文档，以及原文发布日期是否满足指定范围。缺少证据时，可在原计划的来源中继续补搜。
4. 返回引用片段、文档身份、日期、请求用量和剩余缺口，交给 Agent 判断片段是否真正支持结论。达到可供核验的覆盖或用尽预算时停止。

这些检查是字面证据覆盖，不是语义判分或事实核实。关键词出现在正文中不代表所问论断成立；日期未知也不代表文件不符合条件。`ok:true` 仅表示取得候选，`complete:false` 保留给 Agent 的最终核验。`coverage.enough_for_agent_review` 表示机器检查未发现上述缺口，不等于答案正确。

## 预算与范围

| 参数 | 默认或范围 |
|---|---|
| `--read-count` | 最多三次原文或补读尝试；可设 1–5 |
| `--min-documents` | 至少一份不同文档；可设 1–3，不代表来源已相互独立 |
| `--require-topic` | 可重复的关键主题；省略时从短检索词提取 |
| `--max-read-characters` | 每份返回文本上限 12000 字符；可设 1000–24000 |
| `--max-requests` | 整项调研共享，默认 12 次；搜索、目录、正文与补读均计入 |
| `--max-seconds` | 默认 45 秒，每次请求受剩余时间限制；不是底层 DNS 的硬截止 |
| `--page-count` | 南网当前页无命中时最多查两页；可设 1–3，仅跟随页面公布的下一页 |

显式指定 `--page` 时只读取该页。普通 `search` 不自动翻页。南网标题会截断，有限页无匹配不能证明全站没有相关项目。不要通过重新启动命令绕过整项任务的调用限制。

## 原文、PDF 与日期

原生读取覆盖已适配的官方技术文档、能源局、统计局、公共资源平台、南网和巨潮 PDF 域名，具体域名用 `capabilities --provider native-reader` 查询。网页提取文章区域，已定位锚点时优先读该节；未识别到文章区域时标记为可见页面文本。导航和目录不能自动视为所需事实。

PDF 使用本机已有的 `pdftotext`，最多请求前十页。没有该工具、文档为扫描件或无法提取时保留缺口，不自动安装，不称已读全文。截断和页范围随结果返回。其他网页继续使用当前模式允许的阅读服务，或由 Agent 复用宿主工具。

检索日期与原文发布日期分别记录。原生页面日期仅取明确元数据或“发布时间”等标签，不从 URL 或检索时间补造。统计期、生效日期、截止时间需要从具体段落核对。

采购截止时间会从带明确标签及紧邻日期的原文中提取，包含引用位置；泛泛提及“投标截止时间当天”不当作具体日期，也不据此推断项目仍在招标。方法名检索会在页面实际存在的锚点中定位，不拼造方法链接。

## 文档归并与引用

同一网页的锚点或常见追踪参数变化按一份文档归并，`retrieved_by` 保留每家来源与原排名；版本路径和有意义的查询参数保留。相同标题的跨站页面标记为可能转载，不宣称已经确认相互独立。结果优先展示已读且命中关键主题的文档，原供应商评分不混排。

正文与搜索摘要分别返回。`documents.passages` 是带行位置的原文片段，不是生成答案；`read_characters`、`truncated` 和 `extraction_scope` 说明已读取的范围。缺口在 `coverage.gaps` 中列出，便于 Agent 继续核验或如实解释限制。

## 来源状态与升级

`sources` 离线显示接入范围、逐动作最近检查和过期状态，七天以前的样例不再当作当前可用性。每周巡检更新公开快照及中英文状态页；匿名额度、网络和网站变化仍可能影响下一次请求。临时限频与访问拒绝按本机冷却处理，不借新身份重试。

版本检查和更新见[安装教程](../INSTALL.zh-CN.md)。默认安装包保留运行代码与使用文档，历史题集、调研和评测数据留在仓库及源码包中。

显式运行 `sources --refresh` 可用一次公开请求更新本机缓存；不读取 Key、不修改安装文件，也不逐个试搜。普通查询仍使用离线快照。

## 核对片段是否能作答

先列出问题必须回答的事实点，再检查片段是否保留条件、否定、单位、项目身份和日期类型。`coverage.answer_support` 默认为 `not_assessed`，`answer_review_required` 始终保留；字面检查不生成答案准确率。原生方法读取尽量停止在下一方法或同级标题之前，条件与后果优先一起返回。

南网默认走 `csg-search` 官网关键词表单；上面的有限列表翻页仅适用于显式 `--provider csg`。文件获取截止、投标截止与非招标响应截止分别保存在 observations，不据此推断在招状态。

## 按需附件与完整示例

问题需要通知中没有的细节时，可以补读发布者实际链接的一份相关 PDF；操作类问题的示例被明确放在其他页面时，可以再读一个已公布的示例链接。只允许原生阅读范围内的同站链接，不展开外站、带凭据的 URL、递归链接或无关附件。

补读共用当前 `--read-count`（默认三次）、HTTP 预算和剩余时间，分别用 `--attachments off`、`--context-links off` 关闭。只定位出处、或已有片段足以提供主题与数值时不下载附件。片段是否回答了所需事实，仍由 Agent 核对。

补读文档保留 `relationship`、`parent_document_id`、`parent_url`、`follow_up_reason` 和 `date_context`；父文档记录 `follow_up_reads` 及已读取的附件 URL。关闭、失败或预算不足会保留明确缺口。发布日期筛选继续作用于通知，不能把通知日期补成 PDF 的发布日期。

PDF 使用已有的 `pdftotext`，请求第 1–10 页。`pdf_pages_extracted` 列出实际返回文本的页，`passages.pdf_pages` 标记引用所在页，不表示已读取整份文件。缺少工具、扫描件或访问拒绝时保留通知及缺口，不自动安装或改走付费阅读。

代码优先保留发布页面中的完整 HTML 代码块，上限 1800 字符，保留缩进和错误分支两侧。超出返回文本范围的代码块不标记完整。`context_complete` 只说明保留了对应的发布代码块，不代表整套程序完整或回答已被核实。
