# Agent 搜索评测：2026-11-08

**简体中文** | [English](2026-11-08-agent-search.en.md)

这组评测检查 Agent 能否为真实问题找到可供进一步核对的来源，涵盖中文政策、统计、新闻、英文技术文档、开源项目、论文、金融公告和社区讨论。[查看题集](../agent-search-cases.json) · [查看脱敏结果](2026-11-08-agent-search.data.json)

## 本次结果

2026-11-08，北京时间，在同一网络环境下顺序运行。8 道题各执行一次免费模式和无 Key Smart，共 16 次检索。两种模式均使用免 Key 路由，不能据此比较付费服务效果。

| 指标 | 免费模式 | Smart（无 Key） |
|---|---:|---:|
| 检索任务 | 8 | 8 |
| 至少返回一条结果 | 8 | 8 |
| 检索耗时中位数 | 929 ms | 872 ms |
| 最短—最长 | 456–3005 ms | 116–1082 ms |

每次均为单次观察，耗时仅包含脚本内检索，不包含启动进程、Agent 思考、阅读原文或生成回答；服务限额、网络及缓存会影响结果，不应据此认定两种模式谁更快。记录到 16 次免 Key 请求，无带 Key 请求及接口费用；不包括模型费用。首次与复测均未调用带 Key 服务。DeepSeek 账号此前返回 402，本轮没有重复调用；其他带 Key 服务也未进行在线质量测试。

## 人工查看结果

逐条查看返回标题、链接、日期和搜索摘要，确认各题至少有一个与任务相关的候选链接。**这不是对原文的逐条核验，也不是答案正确率或时效性通过率。** “最新”题需要继续核对原站；论文题的前几条混入了较宽泛的研究，相关论文出现在更后的位置。

| 题目 | 本次观察 |
|---|---|
| 海上风电政策 | 找到能源局相关政策和新闻，需区分发布日期与生效日期。 |
| 国家统计局数据 | 找到官方数据发布栏目与统计发布页面；最新程度需再到原站核验。 |
| 中文 AI 新闻 | 找到标有当天日期的报道；日期为搜索结果所提供，未逐篇复核。 |
| Python TaskGroup | 找到 Python 官方文档页面，具体异常处理需要阅读正文。 |
| GitHub 项目 | 使用完整仓库名后，找到 `microsoft/markitdown`。 |
| 检索增强生成论文 | 找到相关论文，但前几条中有主题较宽的结果。 |
| 巨潮资讯年度报告 | 限定巨潮域名后找到年度报告 PDF；报告内容未读取。 |
| Hacker News 讨论 | 找到 SQLite 讨论链接，多数较旧；本题没有要求近期结果。 |

## 发现与调整

首轮 GitHub 查询使用 `microsoft markitdown`，前五条没有目标仓库；复测保留用户提供的 `microsoft/markitdown`，目标排在首位。首轮金融查询没有限定站点，前五条未找到巨潮公告；复测使用巨潮定向搜索，找到了年度报告。两题的查询条件发生了变化，因此这是查询方式的案例，不是同条件的算法提升。Skill 指令已加入这两种做法。

免费模式与无 Key Smart 在这组条件下走相同的免费路由；付费配置下的 Smart、各渠道的持续可用性，以及答案正确性仍需另行评测。检索结果是外部索引快照，日期和链接可能变化。

## 复现

```bash
python3 scripts/benchmark.py --corpus evaluations/agent-search-cases.json --modes free,smart --keyless --live --limit 8 --max-requests 48 --timeout 8 --count 5 --output /tmp/xcoze-benchmark.json
```

`--keyless` 不读取本地配置或环境变量中的密钥，并在请求发送前拒绝带 Key 接口。在线查询会发送给公开来源；结果中的摘要供本地检查，公开前应移除并检查隐私。无 `--live` 时只生成计划。需要比较付费模式时，单独配置并明确选择，费用按服务商账单核对。
