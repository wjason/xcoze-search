## 逐题人工复核样例

| 题目 | 核验结论与范围 |
|---|---|
| TaskGroup 任务失败 | 首批片段偏重特殊异常，需要 Agent 追加一次原文读取；随后确认普通非取消异常会取消剩余任务，并归并相应异常。记录这次补读，不宣称首次字面覆盖即完成回答 |
| Go WithCancelCause | 原文说明记录非空取消原因，并可通过 Cause(ctx) 取得 |
| Rust OnceLock.get_or_init | 定位页面实际存在的方法锚点；示例展示初始化及后续复用已有值，未据此声称已核验所有并发边界 |
| 储能规模化行动方案 | 原网页日期为 2025-08-27，档案日期为 2025-09-12；读取的是通知页，不是全部政策附件 |
| 广东储能采购截止时间 | 从原文明确标签取得 2026-11-26 09:00，与 2026-11-05 的公告日期分开；不据此保证项目仍可投标 |
| 贵州茅台 2024 年报 | 首页包含公司代码 600519、报告年度和公司身份；最多提取前十页，未声称读取全部 143 页 |

三道故意缺口题分别要求：原文日期必须落在窄区间、正文必须包含不存在的精确标记、只允许一次 HTTP。它们分别保留日期冲突、缺少主题和未读正文/预算不足，没有把候选链接标为完整研究。

## 根据核验修正

- 公告目录会进入页面实际公布的正文地址，两次请求计入同一预算。
- 引用片段优先覆盖尚未展示的主题，避免重复标题占满输出；截止时间问题优先展示紧邻明确日期的标签段落。
- Rust 方法焦点使用页面实际存在的 ID，不拼造方法链接。
- 相同文档去除常见追踪参数后归并，保留各搜索来源、版本路径与可能转载关系，不比较供应商原始分数。
- 原生读取的拒绝与冷却按站点分开，PDF 仅使用已有提取工具；未读附件单独列出。

## 公开来源巡检

本次另行检查了 89 项公开动作，79 项通过、7 项受限、3 项无命中。该巡检检查各个入口本身，包含匿名 Exa/Parallel；与上方同时关闭两者的调研验收分开，不混为同一组条件。

[状态页](../../references/source-status.md)按适配范围、最近检查和本次结果展示；[公开快照](../../references/source-health.json)不含查询正文、凭据和账号错误。七天以前的样例在 CLI 中标记过期。每周工作流会重新生成公开快照及中英文状态页。

修复了此前线上巡检中断的根因：无值图片 alt 属性产生空值，导致整轮文本解析抛错。现在缺少 alt 时按空文本处理，每项失败和阶段进度都会保留，异常入口不会丢掉其他检查结果。

## 运行与发布验证

257 项离线测试覆盖原文提取、已公布的正文/方法链接、日期、候选与原文分离、重复归并、拒绝后的停止、跨站点冷却、任务预算、更新校验、保留备份和状态过期。源码、Skill 元数据、安装包及发布说明统一为 v0.10.0。

正常安装包保留运行代码和使用文档，历史题集和评测留在源码包及仓库；文件清单包含 SHA-256 校验。安装与恢复不修改配置目录中的 Key 或偏好。多平台离线检查与线上接口样例分别判断，不将本机一次通过推广为所有网络环境的保证。

## 复现

```bash
python3 evaluations/evaluate_research.py --live --output /tmp/xcoze-research.json
python3 evaluations/check_sources.py --live --output /tmp/xcoze-public-check.json --health-output references/source-health.json
python3 evaluations/build_source_status.py
```

不加 `--live` 的评测仅生成离线计划。时间固定的题目与滚动列表可能在后续运行中不再重合，失败应保留。有关用户用法、读取边界和升级见[调研流程](../../references/research.md)与[安装教程](../../INSTALL.zh-CN.md)。
