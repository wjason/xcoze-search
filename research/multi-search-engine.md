## 实现方式

| 方面 | 观察 |
|---|---|
| 搜索入口 | 客户端通过招聘通的平台网关提交任务，安装包没有列出可供用户独立选择的多个上游搜索引擎 |
| 用户凭据 | 用户无需配置上游搜索 Key；平台维护任务身份及账户关联 |
| 收费规则 | 包内规则写明首次成功搜索免费，此后绑定账户并按每次 0.10 元收费；成功但零结果也计一次 |
| 检索规模 | 默认请求 30 条，最多 50 条；结果不足时保留实际条数 |
| 交付 | 平台生成 PDF、Markdown 和 CSV，客户端下载并检查文件与搜索结果的一致性 |
| 恢复与复用 | 使用原请求标识继续查询状态、下载和导出，避免重复发起搜索；结果正常保留 30 天 |
| 来源说明 | 保留原链接与已有日期，结果序号表示检索顺序，摘要不等同原文核验 |

这些信息说明该项目重视检索成果的交付和恢复。安装包本身不足以判断其底层搜索覆盖、相关性、速度或收费服务的实际稳定性。

## 在 xcoze search 中的应用

xcoze search 继续提供多来源检索和按需阅读。此次新增的能力是搜索结果的本地保存与复用：

- 用户需要时生成 `results.json`、`report.md` 和 `links.csv`，报告可选中文或英文。
- 从已保存的 JSON 更换报告语言或导出目录，不联网、不重新检索。
- 保留来源、原排名、链接、已有日期和错误状态，不将重复链接当成独立证据。
- 保存失败后保留已完成的搜索输出，允许仅重试本地导出。
- 保护已有不同文件，使用标准库完成导出，不增加运行依赖。

平台账户、报价、使用记录和服务端报告不纳入本次适配。PDF 导出仍可作为后续扩展；当前的 Markdown 和 CSV 交付在本机完成。

使用方法见[输出契约](../references/output.md#保存和导出搜索结果)。
